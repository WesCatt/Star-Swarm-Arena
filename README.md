# Star Swarm Arena

一个基于 HTML5 Canvas 的双人同屏对战小游戏。玩家控制两艘母舰争夺星球、积累无人机并摧毁对方母舰获胜。

## 运行方式

通过本地 Web 服务器访问本目录即可，例如：

- `http://localhost/star_swarm_arena/`

## 控制说明

- `P1 蓝方`：`W A S D`
- `P2 红方`：方向键
- 触摸设备：左右半屏双虚拟摇杆

## 当前实现

- 开始界面、道具图例、开始按钮与双按钮同时按住开局
- 双母舰移动、生命值、自动生产无人机
- 无人机 Boids 群体行为、索敌与攻击
- 星球占领、生命恢复、占领后提高无人机上限并提供支援
- 七种道具效果
- 动态相机缩放、HUD、胜利界面
- 高分屏适配与窗口响应式
